DECLARAÇÃO DE AMOR — SITE

Atualização:
A folha da carta agora é criada diretamente com CSS no site.
Não usa a imagem enviada como papel.

A carta é uma folha clara, simples e elegante, com:
- linhas bem suaves;
- textura discreta criada pelo CSS;
- sombra para parecer uma folha sobre o fundo;
- pequeno detalhe de coração;
- texto que se ajusta e rola dentro da folha no celular.

Para escrever sua declaração:
No index.html, procure por:
const CARTA = `COLOQUE SUA CARTA DE AMOR AQUI.`;
